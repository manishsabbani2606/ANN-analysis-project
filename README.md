
About :

This project focuses on Sentiment Analysis of movie reviews, where user-provided text is classified as Positive or Negative using a Deep Learning–based Recurrent Neural Network (RNN) model.

The application analyzes the emotional tone of written movie reviews by learning patterns in language, word order, and context. It helps demonstrate how Natural Language Processing (NLP) techniques can be combined with neural networks to extract meaningful insights from unstructured text.

🔍 How It Works

User enters a movie review as free-form text.

The text is preprocessed using tokenization and padding.

The processed input is passed into a trained Simple RNN model.

The model outputs a sentiment score.

Based on the score, the review is classified as Positive or Negative.

🧠 Model & Techniques Used

Natural Language Processing (NLP)

Tokenization and sequence padding

Embedding layer for word representation

Simple Recurrent Neural Network (RNN)

Binary classification using Sigmoid activation

🎯 Project Objective

The goal of this project is to build a simple yet effective sentiment analysis system that showcases the practical application of RNNs in text classification and provides an interactive interface for real-time predictions.
